# EventFlow — управление участниками мероприятия

Локальное одностраничное приложение для организатора образовательного события.
Превращает разрозненные CSV-списки регистраций в управляемый список участников:
подтверждения, лист ожидания, отметки о приходе.

Учебный проект курса (урок 7): практика работы с OpenCode — агенты, правила,
импорт/валидация данных, резервные копии.

## Возможности

- Дашборд: всего активных, подтверждены, пришли, лист ожидания
- Поиск по имени, email и компании; фильтр по статусу и типу билета
- Сортировка по имени и дате регистрации
- Карточка участника: просмотр, редактирование, отметка прихода, архивация (с отменой)
- Импорт CSV с предпросмотром: счётчики строк, ошибки с номерами строк и причинами,
  дубликаты по email, импорт только корректных строк одной транзакцией
- Экспорт/восстановление резервной копии JSON (`schemaVersion`, `exportedAt`,
  `event`, `participants`, `activity`) с проверкой структуры перед заменой
- Журнал последних действий и уведомления о результатах операций
- Данные хранятся локально в браузере, сервер не нужен

## Запуск

Откройте `app/index.html` в браузере. Сборка не требуется.

Тестовые данные: `data/participants.csv`, файл с ошибками для проверки импорта —
`data/participants-with-errors.csv`, настройки события — `data/event-settings.json`.
