# Проверка готовности EventFlow

## Данные и база

- [ ] После перезагрузки браузера участники сохраняются.
- [ ] Данные находятся в IndexedDB `eventflow-db`, а не в массиве или localStorage.
- [ ] В базе есть `participants`, `settings` и `activity`.
- [ ] Email уникален без учёта регистра.
- [ ] Архивные записи не входят в показатели и обычную выдачу.

## CRUD и форма

- [ ] Участника можно добавить, открыть, изменить и архивировать.
- [ ] Имя и корректный email обязательны.
- [ ] Статус и тип билета выбираются только из допустимых значений.
- [ ] Check-in недоступен для неподтверждённого участника.
- [ ] Ошибка объясняет, что исправить.
- [ ] Архивацию можно отменить из уведомления.

## Поиск и представление

- [ ] Поиск работает по имени, email и компании.
- [ ] Работают фильтры статуса и билета.
- [ ] Работает сортировка по имени и дате.
- [ ] Показатели пересчитываются после каждого изменения.
- [ ] Пустой результат объясняет, как сбросить условия.

## CSV

- [ ] `data/participants.csv` показывает 12 корректных строк.
- [ ] `data/participants-with-errors.csv` показывает 2 корректные и 6 ошибочных строк.
- [ ] До подтверждения ни одна строка не попадает в IndexedDB.
- [ ] Для каждой ошибки показаны номер строки и причина.
- [ ] Корректные строки импортируются одной транзакцией.
- [ ] Дубликаты по email не создаются.

## Резервная копия

- [ ] Экспорт скачивает валидный JSON с `schemaVersion: 1`.
- [ ] Восстановление сначала показывает предпросмотр.
- [ ] Неверный или несовместимый JSON не меняет базу.
- [ ] После подтверждения восстановленные данные видны после перезагрузки.

## Интерфейс

- [ ] Есть loading, empty, error и success.
- [ ] Интерфейс читаем на ширине 1440, 768 и 390 пикселей.
- [ ] Все действия доступны с клавиатуры.
- [ ] Видимый фокус не отключён.
- [ ] Нет сетевых запросов, внешних библиотек и CDN.
